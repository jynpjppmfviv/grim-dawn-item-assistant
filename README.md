## 🕹️ Overview

Grim Dawn Item Assistant provides infinite external stash space, powerful search, set completion tracking, and backup for all your Grim Dawn character items.

Whether you're a newcomer or a veteran, Grim Dawn Item Assistant provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Infinite Stash** | Store unlimited items across categorized tabs outside the game |
| **Instant Search** | Filter thousands of items by name, affix, and stats in real time |
| **Set Tracker** | Highlights missing pieces to complete legendary item sets |
| **Auto Backup** | Automatically backs up character and stash before each session |
